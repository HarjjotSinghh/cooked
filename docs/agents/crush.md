# Crush

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a crush -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.config/crush/skills/cooked/SKILL.md` |
| Project | `.crush/skills/cooked/SKILL.md` |

### Manual

```bash
mkdir -p ~/.config/crush/skills
cp -R skills/cooked ~/.config/crush/skills/cooked
```

## Invoke

`cooked` or description-matched natural language.
