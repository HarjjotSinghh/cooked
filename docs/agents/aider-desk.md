# AiderDesk

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a aider-desk -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.aider-desk/skills/cooked/SKILL.md` |
| Project | `.aider-desk/skills/cooked/SKILL.md` |

### Manual

```bash
mkdir -p ~/.aider-desk/skills
cp -R skills/cooked ~/.aider-desk/skills/cooked
```

## Invoke

`cooked` / `did I cook` after a coding session wraps.

## Notes

Agent Skills layout via AiderDesk. Classic Aider (non-Desk) does not use this path — use AiderDesk or install into a skills-compatible harness.
