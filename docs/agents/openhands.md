# OpenHands

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a openhands -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.openhands/skills/cooked/SKILL.md` |
| Project | `.openhands/skills/cooked/SKILL.md` |

### Manual

```bash
mkdir -p ~/.openhands/skills
cp -R skills/cooked ~/.openhands/skills/cooked
```

## Invoke

`cooked` / natural language after a task is claimed complete.
