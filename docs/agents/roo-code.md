# Roo Code

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a roo -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.roo/skills/cooked/SKILL.md` |
| Project | `.roo/skills/cooked/SKILL.md` |

### Manual

```bash
mkdir -p ~/.roo/skills
cp -R skills/cooked ~/.roo/skills/cooked
```

## Invoke

In Roo Code: `cooked`, `/cooked`, or `am I done with this feature?`
