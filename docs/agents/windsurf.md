# Windsurf

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a windsurf -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.codeium/windsurf/skills/cooked/SKILL.md` |
| Project | `.windsurf/skills/cooked/SKILL.md` |

### Manual

```bash
mkdir -p ~/.codeium/windsurf/skills
cp -R skills/cooked ~/.codeium/windsurf/skills/cooked
```

## Invoke

In Windsurf Cascade / agent chat: `cooked` or `did I cook after this change?`

## Notes

Global path is under Codeium's Windsurf config (`~/.codeium/windsurf/`), not `~/.windsurf/`.
