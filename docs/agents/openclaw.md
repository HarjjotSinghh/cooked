# OpenClaw

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a openclaw -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.openclaw/skills/cooked/SKILL.md` |
| Project | `skills/cooked/SKILL.md` (repo root `skills/`) |

### Manual

```bash
mkdir -p ~/.openclaw/skills
cp -R skills/cooked ~/.openclaw/skills/cooked
```

## Invoke

`cooked` or natural language triggers from the skill description.

## Docs

- [OpenClaw skills](https://docs.openclaw.ai/tools/skills)

## Notes

OpenClaw's project path is `skills/` at the workspace root (not `.openclaw/skills/`). The global path is `~/.openclaw/skills/`.
