# JetBrains Junie

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a junie -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.junie/skills/cooked/SKILL.md` |
| Project | `.junie/skills/cooked/SKILL.md` |

### Manual

```bash
mkdir -p ~/.junie/skills
cp -R skills/cooked ~/.junie/skills/cooked
```

## Invoke

In Junie agent chat: `cooked` or `am I done with this change?`
