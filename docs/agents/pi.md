# Pi

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a pi -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.pi/agent/skills/cooked/SKILL.md` |
| Project | `.pi/skills/cooked/SKILL.md` |

### Manual

```bash
mkdir -p ~/.pi/agent/skills
cp -R skills/cooked ~/.pi/agent/skills/cooked
```

## Invoke

```text
/cooked
```

Or skill name / natural language triggers in the description.
