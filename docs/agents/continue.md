# Continue

## Install

```bash
npx skills add HarjjotSinghh/cooked --skill cooked -a continue -g -y
```

| Scope | Path |
|---|---|
| Global | `~/.continue/skills/cooked/SKILL.md` |
| Project | `.continue/skills/cooked/SKILL.md` |

### Manual

```bash
mkdir -p ~/.continue/skills
cp -R skills/cooked ~/.continue/skills/cooked
```

## Invoke

In Continue agent mode: `cooked` or `did I cook?` after finishing work.

## Notes

Same `SKILL.md` as every other agent. No Continue-specific adapter required.
