# Antigravity

## Install

```bash
# IDE / primary
npx skills add HarjjotSinghh/cooked --skill cooked -a antigravity -g -y

# CLI variant
npx skills add HarjjotSinghh/cooked --skill cooked -a antigravity-cli -g -y
```

| Agent | Global path | Project path |
|---|---|---|
| `antigravity` | `~/.gemini/antigravity/skills/cooked/` | `.agents/skills/cooked/` |
| `antigravity-cli` | `~/.gemini/antigravity-cli/skills/cooked/` | `.agents/skills/cooked/` |

### Manual

```bash
mkdir -p ~/.gemini/antigravity/skills
cp -R skills/cooked ~/.gemini/antigravity/skills/cooked
```

## Invoke

`cooked` / `/cooked` after a feature is claimed done.
